# Contributing to Marcbantu Africa

Thank you for considering contributing! This guide covers the workflow.

---

## Code of Conduct

Be respectful. We're building tools for farmers who depend on us. Quality matters.

- No harassment, discrimination, or personal attacks
- Assume good faith
- Focus on what's best for farmers

---

## Ways to Contribute

- **Bug reports** — open an issue with reproduction steps
- **Feature requests** — describe the problem, not just the solution
- **Code** — submit a pull request
- **Documentation** — improve clarity
- **Translations** — Swahili, French, Amharic welcome
- **Testing** — try beta features, report issues
- **Content** — write tutorials, record videos

---
